
# Spec V2

- **What it does:** Given a school's official name, tells you whether that same school appears under a different spelling in Renée's notes, the grant agreement, or QuickBooks — so staff stop guessing whether "Masterman" and "Julia R. Masterman" are the same school.
- **Input:** A school's official name, chosen from a fixed list.
- **Output:** The name variant used in each of the three sources for that school (or "no record" if a source has none).
- **Done when:** Given an official school name, the system returns the matching variant used in each source (yes/no).
