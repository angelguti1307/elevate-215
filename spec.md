# Spec V1

- **What it does:** Records school visit notes so staff can look up a school's latest visit without waiting or reconciling different school names.
- **Input:** A visit entry with a school name from a fixed list, visit date, and note text.
- **Output:** The school's most recent visit record: school name, visit date, note text, and the note's age in days.
- **Done when:** Given a school name from the list, the system returns that school's most recent visit record and its age in days (yes/no).
